# 👋 About Me

I'm **Snehith Kumar**, a Computer Science Engineer focused on building practical systems at the intersection of **Artificial Intelligence and Software Engineering**.

I enjoy taking a problem from an idea to a working product — understanding the workflow, designing the architecture, building APIs and AI pipelines, integrating models and tools, testing failure cases, and deploying the system.

My strongest areas are **Python, Generative AI, Agentic AI, LLM applications, RAG, Computer Vision, backend engineering, and full-stack development**.

- 🤖 Building applications with **LLMs, Agentic AI, RAG and Multimodal AI**
- 🧠 Working with **LangGraph, LangChain, Gemini, LLaMA, Groq, Hugging Face and PyTorch**
- 🔧 Building backend systems with **Python, FastAPI, Flask, Node.js and Express**
- 🌐 Developing full-stack applications using **React, TypeScript and JavaScript**
- 🗄️ Working with **PostgreSQL, MySQL, Supabase, Redis and ChromaDB**
- ⚡ Building asynchronous and event-driven workflows
- 🧪 Using **Pytest, Vitest, automated validation and CI/CD**
- 🐳 Containerizing applications using **Docker**
- 🔍 Interested in **AI agents, intelligent automation, developer tools and production AI**
- 💡 Learning unfamiliar technologies by building real systems around them
